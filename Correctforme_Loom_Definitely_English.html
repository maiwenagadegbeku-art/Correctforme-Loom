🔑 Obtenir une clé API Anthropic
3 étapes · 5 minutes · Gratuit à créer
1
Créer un compte sur console.anthropic.com
Clique sur "Sign up" et crée ton compte avec ton e-mail.
2
Générer une clé API
Dans le menu gauche → API Keys → Create Key. Copie la clé affichée (elle commence par sk-ant-).
3
Ajouter du crédit
Menu → Billing → ajoute 5 € minimum. C'est ce crédit qui sera débité à l'usage.
💶 Coût estimé pour ton usage :
170 élèves × 10 devoirs × ~0,003 € = environ 5 € par an
Le crédit ne expire pas. Tu peux commencer avec 5 € et voir.
